# Micro Grinding India - Transformation First

Presentation-ready static website concept created from the supplied Micro Grinding India company profile and standalone MG logo.

## Run locally

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Cloudflare Pages

- Framework preset: None
- Build command: leave blank
- Build output directory: `/`
- Root directory: `/`

The preview includes `noindex` metadata and a restrictive `robots.txt`. Remove those only after client approval and final content verification.

## Source discipline

All company facts, contact information, machine/project descriptions and photography used in the concept come from the supplied company profile. External design references were not used as content sources.
